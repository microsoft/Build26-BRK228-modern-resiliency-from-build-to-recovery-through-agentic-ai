# High-Level Topic Summary


## Session Arc

- The presentation frames resiliency as a full lifecycle from build-time design decisions to recovery validation in production.
- It uses a Start resilient, Get resilient, Stay resilient model to organize capabilities and demos.

## Core Resiliency Model

- Three pillars are highlighted: infrastructure resiliency, data resiliency, and cyber resiliency.
- The goal is to help teams plan, deploy, validate, monitor, and recover workloads with stronger posture and continuity.

## Start Resilient Themes

- Shift resiliency left by validating infrastructure as code before deployment.
- Use Agentic AI workflows with Resiliency Agent and Azure MCP Server to generate and assess zonally resilient templates.
- Use Azure Advisor recommendations in development tools to catch gaps and retiring SKU risks early.

## Get Resilient Themes

- Improve posture for existing workloads with application-centric views and service grouping.
- Define zonal resiliency goals and use guided remediation patterns to reduce non-resilient resources.
- Expand into data and cyber resiliency, including backup-oriented recovery posture and workload-based configuration.
- Emphasize prioritization at scale through Azure Advisor AI-powered recommendation ranking and action planning.

## Stay Resilient Themes

- Move from static posture to continuous validation through drills and observability.
- Highlight chaos engineering patterns, including zone-down and real-world outage simulations.
- Reinforce regular resilience testing for both traditional workloads and AI-driven applications.

## Platform and Tooling Focus

- Azure MCP Server as the connective layer for AI-assisted cloud operations.
- Azure Advisor for recommendations, posture insights, and prioritization.
- Azure Chaos Studio for fault injection and resiliency validation exercises.
- GitHub Copilot and Azure Copilot experiences are presented as workflow accelerators.

## Demonstration Thread

- Multiple demos showcase end-to-end scenarios: generating resilient infrastructure as code, evaluating and remediating existing templates, improving resiliency posture, and validating recovery readiness.
